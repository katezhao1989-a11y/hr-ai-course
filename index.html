1.2 HR的三重焦虑

AI时代，HR在焦虑什么？

技能焦虑

"我会不会被AI取代？"

过去熟练的Excel、PPT、流程操作，在AI面前瞬间贬值

新技能（Prompt工程、AI训练、数据分析）门槛高、学习曲线陡峭

—— 不是不想学，是不知道学什么、怎么学

角色焦虑

"HR的价值到底是什么？"

事务性工作被AI接管，HR的"存在感"越来越低

业务部门开始直接用AI工具，绕过HR做招聘、做培训

—— 不是没价值，是价值被AI稀释了，找不到新的定位

方向焦虑

"HR的下一步往哪走？"

三支柱架构动摇，岗位名称和职责边界模糊

新兴岗位（AI训练师、智能体设计师）听起来很酷，但不知道怎么转型

—— 不是不想变，是看不清方向，害怕选错路

1.2 破局之道

三重焦虑的解法：回归本质，拥抱外延

技能焦虑 → 内核+外延

不要追每一个新工具

守住内核：商业敏锐度、问题定义、故事化、伦理判断

扩展外延：学会用AI放大内核能力，而不是让AI替代内核

角色焦虑 → 价值升维

不要和业务部门"抢"工具使用权

向上升维：从"执行者"变成"规则设计者"和"质量守门人"

向下深耕：AI处理不了的复杂人际、伦理判断、文化塑造，才是HR的护城河

方向焦虑 → 能力迁移

不要被新岗位名称吓到

看清本质：AI训练师=懂业务的HR+懂AI的表达；智能体设计师=懂流程的COE+懂逻辑的结构化思维

能力可迁移：HR过去积累的专业知识，是训练AI最稀缺的"燃料"

核心心法：焦虑来源于"只看见变化，没看清不变"。守住不变的内核，变化的外延自然清晰。

1.3 HR三支柱的"终结"与"重生"

从"三角凳"到"智能铁三角"

"就连三支柱提出者戴维·尤里奇本人，后来都公开反思、甚至怀疑这套体系，明确说要根据企业现实去调整、去适配。"
传统角色新角色进化本质
COE（专家中心）→ HR智能体设计师从"设计政策"到"设计AI规则与行为边界"
HRBP（业务伙伴）→ 战略顾问+AI指挥官从"跑业务"到"管理AI代理+战略共创"
SSC（共享中心）→ AI执行体训练中心从"处理事务"到"训练AI+监控质量"

核心结论：三支柱不会消失，但会发生结构性萎缩和职能跃迁。企业不再需要庞大的COE团队，但需要1-2个"AI-HR架构师"。

第二部分

本质洞察

HR的"变"与"不变"

"AI改变的是HR的'手'，不是HR的'心'。AI替代的是'重复'，不是'关系'。"
2.1 先看"变"

能力的外延与形态

维度过去现在
数据类型结构化数据：问卷、绩效打分、考勤+ 非结构化数据：员工反馈、聊天记录、社交媒体、视频面试
分析深度"发生了什么" → "为什么发生"+ "将会发生什么" → "应该怎么做"
技术门槛需要顶级数据科学家团队HR自己就能做，AI降低了技术门槛
输出形态PPT报告、Dashboard展示直接生成并执行：个性化方案、自动推送、实时干预

核心变化：从"数据分析"进化为"智能决策"

2.2 再看"不变"

HR的专业内核

商业敏锐度

以前：懂业务部门的KPI和人才需求

现在：预判AI对业务人才需求的重塑——哪些岗位会被AI替代？新增什么能力要求？

提出正确问题的能力

AI擅长回答"How"，但不擅长定义"What"和"Why"

判断"哪个相关性值得干预"是人的能力

数据解读与故事化

AI能输出数据，但冰冷的数据不会让人行动

让人行动的，是故事、是共情、是"这说的就是我"的共鸣

伦理判断与偏见识别

机器只会呈现相关性

承担伦理后果、纠正偏见的，永远是人

2.3 内核-外延模型

HR能力的"变"与"不变"关系

能力外延（变）

全量数据分析（结构化 + 非结构化）

预测性 + 处方性洞察

AI工具构建与训练

从展示到直接执行

能力内核（不变）

商业敏锐度

提出正确问题的能力

数据解读与故事化能力

伦理判断与偏见识别

核心结论：AI没有改变HR做什么，而是改变了HR能做到什么程度。

角色重构

HRBP / COE / SSC 的能力跃迁

3.1 HRBP进化

从"业务伙伴"到"战略共创者+AI指挥官"

能力维度传统HRBPAI时代HRBP
业务洞察理解业务部门的KPI和人才需求预判AI对业务人才需求的重塑
数据分析看懂离职率、招聘周期等基础指标驾驭全量数据洞察，判断AI输出的可信度
问题解决用经验和流程解决HR问题定义正确的问题并指挥AI解决
沟通影响用PPT和汇报推动决策用AI生成的个性化数据故事推动决策
方案落地推动培训、调薪、绩效方案的执行直接构建和训练AI Agent执行标准化方案
伦理判断凭经验识别潜在风险系统性识别AI偏见和伦理风险
3.2 COE进化

从"政策专家"到"AI规则架构师"

能力维度传统COEAI时代COE

3.3 SSC进化

从"事务处理中心"到"AI训练与质量中心"

能力维度传统SSCAI时代SSC
事务处理处理入离职、社保、考勤训练AI处理事务，人工处理异常
员工服务接听热线、回复邮件持续优化AI客服的回答质量
流程优化简化流程、减少手工操作设计AI自动化的触发条件和决策逻辑
